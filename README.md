# Ticket Management System

A desktop ticket purchasing platform built with JavaFX and SQL, implementing the complete ticket purchase workflow with authentication, authorization, and multi-layered validation.

## Features

- **Authentication** — password encryption, session management, and role-based access control
- **Full purchase workflow** — event browsing, seat selection, payment, and ticket confirmation
- **Input validation** — multi-layered checks prevent invalid transactions and enforce business rules
- **GUI** — event-driven JavaFX interface with structured navigation between views

## Tech Stack

`Java` `JavaFX` `SQL` `Maven`

## Setup

1. Clone the repo
2. Open in IntelliJ IDEA
3. Configure your SQL connection in `config/db.properties`
4. Run `Main.java`
